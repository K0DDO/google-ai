# ТЗ

## Зачем

Быстро получать пояснение к куску кода через Google AI Mode прямо из VS Code.

## IDE

Visual Studio Code

## Что должно быть

1. Выделил код
2. Нажал Ctrl+Alt+G
3. Открылся Google AI Mode с запросом «поясни этот код…»
4. Если выделения нет — берём слово под курсором
5. В запросе указываем язык файла

## Что не делаем

- Чат внутри VS Code
- Свои сервера и API-ключи
