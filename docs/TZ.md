# Техническое задание — Google AI Mode

## Цель

Плагин для Visual Studio Code, ускоряющий получение пояснения к выделенному фрагменту кода через **Google AI Mode**.

## IDE

Visual Studio Code (Extension API).

## Функциональные требования

1. Пользователь выделяет текст в редакторе.
2. По сочетанию **Ctrl+Alt+G** (или команде / пункту контекстного меню) формируется запрос на русском: просьба **пояснить** код.
3. Открывается браузер с URL Google Search в AI Mode: параметр **`udm=50`**.
4. Если выделение пустое — используется слово под курсором; если и его нет — показывается предупреждение.
5. В запрос подставляется название языка файла (если известно).
6. Слишком длинный код обрезается с пометкой в статус-баре.

## Нефункциональные требования

- Код содержит логику (сборка промпта, проверка выделения) и структуры данных (`Map`, очередь истории).
- Документация в репозитории в Markdown.
- Плагин демонстрируется на защите в рабочем виде.

## Вне скоупа

- Встроенный чат внутри VS Code.
- Собственные API-ключи и серверная часть.
- Парсинг ответа Google обратно в IDE.
