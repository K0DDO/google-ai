### 1. Цель работы

Изучить архитектуру IDE в части подключения сторонних расширений и реализовать рабочий плагин для Visual Studio Code.

### 2. Краткое ТЗ

Плагин по `Ctrl+Alt+G` отправляет выделенный код в **Google AI Mode** с запросом на пояснение на русском языке и открывает ответ в браузере.

### 3. Архитектура IDE и подключение плагина

Visual Studio Code загружает расширения в отдельном процессе Extension Host. Возможности плагина описываются в `package.json` (команды, горячие клавиши). При вызове команды выполняется JavaScript-код расширения, который через VS Code API читает текст из редактора и инициирует внешнее действие (`openExternal`).

Подробнее и блок-схема: см. `docs/ARCHITECTURE.md`.

### 4. Реализация

- `extension.js` — регистрация команды и работа с выделением.
- `queryBuilder.js` — логика промпта, `Map` языков, очередь истории запросов, формирование URL с `udm=50`.

### 5. Документация

- Комментарии JSDoc к функциям и классам в исходниках.
- `README.md`, `docs/TZ.md`, `docs/ARCHITECTURE.md`.

### 6. Демонстрация (сценарий защиты)

1. Открыть папку плагина в VS Code, нажать F5.
2. Выделить фрагмент кода.
3. Нажать Ctrl+Alt+G.
4. В браузере открывается Google AI Mode; дождаться пояснения.
