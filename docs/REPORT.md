## Цель

Сделать плагин для VS Code и разобраться, как расширения подключаются к IDE.

## ТЗ

По Ctrl+Alt+G выделенный код уходит в Google AI Mode с просьбой пояснить его.

## Как подключается к VS Code

В `package.json` указаны команда и сочетание клавиш.  
При нажатии VS Code запускает мой код в Extension Host.  
Код читает выделение через API редактора и открывает браузер.

## Что сделано

## Как показать на защите

1. F5
2. Выделить код
3. Ctrl+Alt+G
4. Показать ответ в AI Mode
