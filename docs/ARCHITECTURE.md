# Архитектура плагина Google AI Mode

## Как VS Code подключает расширения

1. В `package.json` описываются **команды**, **keybindings** и точка входа (`main`).
2. При первом вызове команды VS Code загружает `extension.js` и вызывает `activate(context)`.
3. Команда регистрируется через `vscode.commands.registerCommand`.
4. Плагин использует API редактора (`TextEditor`, выделение) и `vscode.env.openExternal` для открытия URL в системе.

Таким образом сторонний функционал подключается без изменения ядра IDE — только через Extension Host.

## Модули плагина

| Файл | Назначение |
|------|------------|
| `package.json` | Манифест: команда, `Ctrl+Alt+G`, меню |
| `extension.js` | Активация, получение выделения, вызов браузера |
| `queryBuilder.js` | Сборка промпта, `Map` языков, очередь истории, URL с `udm=50` |

## Структуры данных и логика

- **`Map LANGUAGE_LABELS`** — язык редактора → подпись в тексте запроса.
- **`SearchHistory`** — очередь фиксированной длины (массив + `push`/`shift`).
- **Логика:** проверка редактора/выделения → нормализация текста → промпт «поясни…» → `URLSearchParams` → открытие AI Mode.

## Блок-схема работы

```
Старт (Ctrl+Alt+G)
        │
        ▼
 Есть активный редактор? ──нет──► сообщение пользователю ──► конец
        │ да
        ▼
 Есть выделение? ──нет──► взять слово под курсором
        │
        ▼
 Текст пустой? ──да──► предупреждение ──► конец
        │ нет
        ▼
 queryBuilder: язык (Map) + промпт «поясни код»
        │
        ▼
 Собрать URL google.com/search?q=...&udm=50&hl=ru
        │
        ▼
 Записать в историю (очередь) → openExternal → ждать ответ AI Mode
        │
        ▼
 Конец
```
