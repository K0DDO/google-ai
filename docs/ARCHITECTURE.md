# Как устроен плагин

## Коротко про VS Code

Расширение описывается в `package.json` (команда и хоткей).  
VS Code загружает `extension.js` и вызывает `activate`.  
Дальше плагин читает выделение и открывает ссылку в браузере.

## Из чего состоит

- `extension.js` — берёт текст и открывает URL
- `queryBuilder.js` — собирает текст запроса
  - `Map` — язык файла → название
  - очередь — последние запросы

## Схема

```
Ctrl+Alt+G
   ↓
есть выделение? → нет → слово под курсором
   ↓
собрать запрос «поясни код»
   ↓
открыть google.com/search?q=...&udm=50
   ↓
ждать ответ AI Mode
```
