# Google AI Mode

**Автор:** Ананенко Дмитрий Сергеевич, М3215  
**IDE:** Visual Studio Code  
**Название плагина:** Google AI Mode

> **Использование ИИ:** код расширения и документация подготовлены с помощью ИИ (Cursor). Указать при сдаче лабораторной работы №3.

## Описание

Расширение для **Visual Studio Code**: пользователь выделяет фрагмент кода, нажимает **`Ctrl+Alt+G`**, и в браузере открывается **Google Search в режиме AI Mode** (`udm=50`) с готовым запросом *«поясни этот код на русском…»*.

Это **не** приложение Gemini — используется вкладка/режим **AI Mode** обычного Google Search.

## Возможности

| Возможность | Как |
|-------------|-----|
| Пояснение выделенного кода | `Ctrl+Alt+G` или команда «Google AI Mode: Пояснить выделение» |
| Контекстное меню редактора | ПКМ → та же команда |
| Если ничего не выделено | берётся слово под курсором |
| Учёт языка файла | `Map` languageId → название языка в промпте |
| Длинный фрагмент | обрезка под лимит URL |
| История запросов | очередь (FIFO) последних 10 обращений в памяти сессии |

## Как запустить (разработка)

По мотивам [Your First Extension](https://code.visualstudio.com/api/get-started/your-first-extension):

1. Откройте папку `google-ai-mode` в VS Code (**File → Open Folder…**).
2. Нажмите **F5** — откроется окно Extension Development Host.
3. Выделите код → **Ctrl+Alt+G**.
4. Дождитесь ответа AI Mode в браузере (нужен доступ к AI Mode в вашем аккаунте/регионе Google).
