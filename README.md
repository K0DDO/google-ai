# Google AI Mode

**Автор:** Ананенко Дмитрий Сергеевич, М3215  
**IDE:** Visual Studio Code

Плагин для VS Code. Выделяешь код, жмёшь **Ctrl+Alt+G** — открывается **Google AI Mode** с просьбой пояснить этот код.

> Код писался с помощью ИИ (Cursor). Документацию писал сам.

## Что умеет

- хоткей `Ctrl+Alt+G`
- пункт в контекстном меню
- если ничего не выделено — берёт слово под курсором
- подставляет язык файла в запрос
- длинный код обрезает (лимит URL)

## Как запустить

1. Открыть папку плагина в VS Code
2. Нажать **F5**
3. В новом окне выделить код и нажать **Ctrl+Alt+G**

## Файлы

- `extension.js` — команда и открытие браузера
- `queryBuilder.js` — сбор запроса, Map языков, история
- `docs/` — ТЗ, схема, отчёт
